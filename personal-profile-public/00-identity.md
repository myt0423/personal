# 00 · 身份

> 只写「长期不变的」和「AI 必须先知道的」。技术细节放 `02-knowledge/`，项目放 `03-projects/`。

## 基本信息

- **称呼**：主人（直接这样叫，别用「您」以外的敬语铺垫）
- **身份**：学生
- **所在时区**：Asia/Shanghai（UTC+8）
- **语言**：中文为主；技术内容接受英文原文（代码、命令、报错不翻译）

## 一句话自我描述

> 还在找方向，什么都试。

补充：不预设赛道，先广泛试错再收敛。所以给建议时**不要假设我已经选定某个专业方向**，也不要用「你这个阶段应该……」的口气。

## 我在意什么

| 排序 | 在意的东西 | 说明 |
| --- | --- | --- |
| 1 | 搞钱 / 变现 | 任何建议先回答「这东西怎么变成钱」 |
| 2 | 技术成长 | 但只学能落地的，不做纯知识囤积 |
| 3 | 自由时间 / 不被绑住 | 拒绝需要长期绑死时间的事 |

## 我讨厌什么（AI 直接避开）

- 客服腔：「建议您」「希望对您有帮助」「如有疑问请随时告知」
- 复述我刚说过的话再回答
- 「这取决于你的需求」这类不落地的回答
- 复述我已经知道的东西
- 一次抛一堆问题

## 沟通偏好（速查）

| 维度 | 我的选择 |
| --- | --- |
| 结论位置 | 先给结果，再给过程 |
| 详细程度 | 够用就停，不要教科书式铺开 |
| 不确定时 | 直说不确定，别编 |
| 反问 | 只在缺少关键信息时问，且一次只问一个 |
| 称呼 | 主人 |

## 长期目标（3 年以上）

- 找到一条能持续变现、又不用被时间绑死的方向。具体形态还没定，先试。
