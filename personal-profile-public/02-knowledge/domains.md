# 02 · 领域与熟练度

> 目的：AI 知道**哪些不用解释、哪些要展开**。

## 当前自评结论（重要）

**没有自评 A 级的领域，B 级也没填。** 也就是：各方向都试过一点，但没有一项能自称「能教别人、能判断方案取舍」。

对 AI 的直接含义：

1. **不要假设我会任何语言或框架。** 本机实测也没有 Python、Node、git 装好（见 `01-context/environment.md`）。
2. **术语第一次出现要一句话解释**，不要默认我懂（但也不要写教科书）。
3. 但**别把我当完全小白**：已经在实际折腾 DSH 插件、微信数据库加密、内存取证这类事，动手能力在线，缺的是系统性。
4. 判断我能不能做某件事，看**有没有现成路径**，不看「学过没有」。

## 熟练度分级（备用表，以后有了再填）

| 级别 | 含义 | AI 该怎么讲 |
| --- | --- | --- |
| A 精通 | 能教别人、能判断方案取舍 | 直接说结论，不用解释概念 |
| B 熟练 | 能独立干活，细节要查 | 给关键点 + 容易踩的坑 |
| C 了解 | 知道概念，没实操 | 给完整步骤 |
| D 陌生 | 完全不懂 | 先讲清楚是什么、为什么 |

## A 级

- 暂无

## B 级

- 暂无（待补：实际动手最多的方向）

## C 级

- 暂无主动自评；用到时按实际表现记

## D 级 / 想学但没入门

- 后端 / 数据库
- 机器学习 / 模型训练
- 变现 / 运营 / 卖东西

## 我的判断偏好

- 方案对比时，我更看重：**上手快，今天就能看到东西**
  → 意味着：**先给能跑的最小版本，不要先讲架构**。能 30 分钟见到效果的路，优先于更优雅但要走三天的路。
- 我反感的技术叙事：
  - 「零基础月入过万」这类变现话术
  - 堆术语、不讲人话的
- 我愿意为哪些东西多花时间：能直接换成钱或直接省时间的（工具链、自动化、内容生产）
