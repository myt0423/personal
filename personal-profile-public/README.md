# 个人档案 · 公开层（Public Layer）

> 这一层是**给 AI 读的**：任何 AI、任何设备、不用登录就能读到这里全部内容。
> 私有层（身份细节、账号、财务、会话记录）**不在这个仓库**，留在本机。

## 为什么分两层

| | 公开层（本仓库） | 私有层（本机，不上传） |
| --- | --- | --- |
| 内容 | 契约、表达风格、决策偏好、技术方法、环境栈、项目概况 | 真实身份细节、账号邮箱、社交标识、会话沉淀 |
| 谁能读 | 任何 AI（裸链接即可） | 只有我自己 |
| 作用 | 让 AI 一进来就懂「怎么跟我说话、按什么标准判断」 | 让 AI 懂「我是谁、手上有哪些具体资产」 |

**判断标准**：这段话如果被陌生人看到，我会不会不舒服？会 → 私有层。

## 结构

```text
├─ AI-CONTRACT.md      给 AI 的读取契约（先读这个）
├─ PROMPT.md           「一段话」提示词，复制即用
├─ 00-identity.md      身份定位（粗粒度）
├─ 01-context/
│   ├─ environment.md  系统与工具链（已脱敏）
│   ├─ work.md         现状与重心
│   └─ constraints.md  行为边界
├─ 02-knowledge/
│   ├─ domains.md      能力分级
│   ├─ techniques.md   方法论与踩坑
│   └─ sources.md      资料源
├─ 03-projects/        项目概况
└─ 04-style/           语言指纹与决策偏好
```

## 怎么用

**第 1 步**：把 `PROMPT.md` 里 A 段那句话复制出来。
**第 2 步**：粘给任何 AI。它会先读 `AI-CONTRACT.md`，再按顺序加载档案。
**第 3 步**：正常聊。有新的长期偏好或结论，它会写回对应文件。

## 维护

- 改动直接提交到本仓库，commit message 写清改了哪一块
- **不要**把私有层内容往这里搬。要放就先脱敏
- 每季度重读 `00-identity.md`，改掉已经不像自己的部分

档案的价值不在「全」，在于 **AI 读完能替你少问 10 个问题**。
